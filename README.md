# 力扣刷题统计仪表盘

本地运行的力扣（leetcode.cn）刷题统计仪表盘：登录自己的力扣账号，自动拉取全部提交记录，生成题单进度、刷题日历、难度/题型分布等多维度统计。

- 🔒 **数据完全留在你自己的电脑上**，不经过任何第三方服务器
- 📦 **零依赖**，装个 Node.js 就能跑，不用 `npm install`
- 🎨 两套皮肤（玻璃拟态 / 新粗野主义）× 日夜双主题

> 第一次打开可以点「先看演示效果」，不登录也能预览界面。

## 快速开始（第一次用看这里）

**第 1 步 · 安装 Node.js**（≥18，只需装一次）

去 <https://nodejs.org/zh-cn> 下载 **LTS 版本**，一路下一步安装即可。

**第 2 步 · 下载本项目**

- 会用 git：`git clone <本仓库地址>`
- 不会用 git：点仓库页面绿色的 **Code → Download ZIP**，解压到任意文件夹

**第 3 步 · 启动**

| 系统 | 操作 |
|---|---|
| macOS | 双击 `启动仪表盘.command`。若提示"无法打开"：右键 → 打开；或在终端执行 `bash 启动仪表盘.command` |
| Windows | 双击 `启动仪表盘.bat` |

会弹出一个终端窗口并自动打开浏览器（<http://127.0.0.1:5881>）。**保持终端窗口开着 = 服务在运行**，关闭窗口即停止。

**第 4 步 · 登录你自己的力扣账号**

1. 点右上角 **⚙**，输入力扣（leetcode.cn）的用户名/邮箱和密码
   - 密码只用于向力扣换取登录会话，**不会被保存**
   - 若力扣要求图形验证码导致登录失败，切换到 **Cookie（备用）**：浏览器登录 leetcode.cn 后按 F12 → 网络面板 → 复制任意请求的完整 Cookie 粘贴进来
   - 不支持手机验证码登录（力扣发短信前有人机验证，本地程序无法代跑）
2. 登录后自动开始同步。首次会拉取你的全部提交历史（提交多的话要几分钟，页面有实时进度）；之后再点 **⟳ 同步数据** 是增量同步，秒级完成

## 功能一览

- **首页大环**：当前主题单的完成进度（在题单卡片点 ★ 可切换展示哪个题单）
- **题单进度**：跟踪官方题单（默认「编程基础 0 到 1」和「热题 100」，可添加任意题单链接）
  - 分组进度条，点分组行展开看每道题（带题号/难度/完成状态，点击跳力扣）
  - 点标题左侧 ▾ 整体收起题单；**↻ 重刷**：进度从此刻重新计数（提交历史不受影响），可随时「撤销」回上一轮
  - 会员章节接口读不到题目，不显示也不计入
- **每日刷题日历**：按年（12 个月年历墙）/ 按月（大格子显示当天做了哪些题）双视图，悬停看当日题目明细，支持跨年翻页
- **核心指标**：不重复题目数（区分新题/复习）、总完成数（同题同日计 1 次）、活跃天数、最长/当前连续打卡、刷最多的题、最常刷题型
- **图表**：难度分布、题型分布（前 15 类标签）、月度趋势
- **明细表**：每题完成次数/难度/标签/最近完成，支持搜索与排序
- 顶部切换统计年份；右上角 **◱ 风格** 切换皮肤、🌙/☀️ 切换日夜主题

## 数据与隐私

- 所有数据保存在项目的 `data/` 目录（已被 `.gitignore` 排除，永远不会被提交到 git）：
  - `config.json` — 登录会话 Cookie（**等同登录凭证，不要发给任何人**）
  - `submissions.json` / `problems.json` / `plans.json` — 提交记录与题库/题单缓存
- 服务只监听本机 `127.0.0.1:5881`，局域网里其他人无法访问
- 登录会话过期后同步会失败，重新登录一次即可

## 实现说明（给好奇的人）

- 提交记录来自力扣 `/api/submissions/` 接口；该接口不返回题目标识，题目信息通过全量题库目录（约 4400 题，缓存 30 天）按标题匹配
- 力扣有约 131 组中文标题完全重名的题（主站题 vs LCR 题），同名题会逐条查提交详情精确归属，结果永久缓存
- 力扣接口限流较严，同步自带退避重试；首次全量同步慢是正常的，之后都是增量
- 无任何 npm 依赖：后端为单文件 Node 服务（`server.js`），前端为原生 JS + 本地化的 ECharts

## 常见问题

- **端口被占用 / 启动失败**：默认端口 5881，可用 `PORT=xxxx node server.js`（Windows：先 `set PORT=xxxx`）换端口
- **同步报错「登录状态已失效」**：重新走一遍 ⚙ 登录
- **做了一道很新的题匹配不到**：同步时会自动刷新题库目录兜底；若仍未匹配，隔天再同步一次
